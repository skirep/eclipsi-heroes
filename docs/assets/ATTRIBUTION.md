# Human anatomy and hair

Source: https://github.com/kblood/CharacterCreator/tree/master/output
License notes: https://github.com/kblood/CharacterCreator/blob/master/LICENSE-NOTES.md
Original geometry, rig, skin, eyes and hair: MakeHuman CC0 system assets, exported through MPFB / CharacterCreator.
Generated `output/*.glb` assets are CC0-1.0 according to the source project's license notes. This project imports only those output assets, not the project's GPL application code.

Files used: `base_body.glb` and `hair_short02.glb`.
Modifications: male and athletic morphs baked into geometry; unused morph targets removed; neutral pelvis smoothed for a fitted costume. Costume materials, mask panels, emblems, cape and armor accessories are created in this project's `characters.js`. The original skin and hair texture maps remain embedded in the GLB files.

Prepared assets: `human-athletic.glb` (2.35 MB) and `hair.glb` (0.81 MB). Four characters share these assets. The skeleton has 53 bones including articulated fingers.

Superman / Batman and Spider-Man / Iron Man remain characters of their respective owners (DC / Marvel). This is an unofficial fan animation; no movie or game character mesh has been extracted or redistributed.

Three.js GLTFLoader, SkeletonUtils and BufferGeometryUtils: Three.js contributors, MIT. See `../vendor/THREE-LICENSE.txt`.
